## 유의사항

1. `_laughs_`의 원문 중복은 한국어 오버레이에서 복제하지 않았으며, 로더의 실제 우선 처리 순서를 확인할 때까지 원문을 수정하지 않는다.
2. 영어식 소유격이나 전치사를 나타내는 `@possessive@`, `@at_foe@`, `@to_foe@` 일부는 한국어 문장 구성에 따라 제거하거나 흡수한다. 몬스터 이름·대상·고유명칭·호출 참조용 토큰은 구조 감사에서 검사한다.
3. `VISUAL:` 및 `SOUND:` 계열을 구분하고, 무작위 문장 변형 수와 `w:` 가중치를 보존한다. 포함된 Lua 분기 전수 검토는 아직 수행하지 않았다.
4. 정적 구조 검사 0건은 **실제 게임 화면의 자연스러운 문장·한국어 조사·폰트·줄바꿈 검증과 다르다.** Windows Tiles 통합 테스트가 필요하다.
5. **65/731은 이 파일의 키 대응 상태**이다. 다수의 원문 키는 단순 참조, 메시지 조합용 단어, 무출력 지시이므로 전체 문장 번역률이나 게임 한국어화율로 간주하지 않는다.

## 다음 번역 우선순위

1. `monspeak.txt`의 기본/우호/도주/혼란 그룹 중 **실제 문장 본문**이 있는 키부터 추가 번역한다. 참조·조합용 단어 및 Lua 템플릿은 별도 분류한다.
2. 고유 몬스터 승리·사망·도발 대사를 묶어 번역하되 캐릭터별 말투와 참조용 변수 문맥을 확인한다.
3. `wpnnoise.txt`의 실제 소음 메시지와 장비 관련 출력으로 범위를 확장한다.
4. `godspeak.txt`와 `shout.txt`는 원문 자체에 한국어가 섞여 있으므로, 중복 작업을 피하고 영어 잔여분만 구분한다.
