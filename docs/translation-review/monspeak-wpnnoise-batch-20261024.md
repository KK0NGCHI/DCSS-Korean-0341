## 변경 내용

- `monspeak.txt` — 직업별 플레이어 유령(전투, 은신, 맨손 격투, 주문 시전, 신성 권능), 다우안·듀베사 상실 반응, 해럴드·모리스·네르갈레·머레이, 오크 전향·베오그 신앙·사도와 신성 존재의 화해 대사.
- `wpnnoise.txt` — **신규 한국어 오버레이 파일**. 공의 방패, 프로스트바이트 도끼, 유죄 선고 삼지창, 자아가 있는 무기의 수다·희귀 발화·기악 소리·웃음과 비명·무기 효과음, 노래하는 검의 침묵 반응.
- 영어 원문은 변경하지 않는다. 미대응 키는 게임 데이터베이스의 원문 폴백으로 유지한다.
- 공통 구조 검사 `audit_monspeak_ko.py`를 무기 텍스트에도 적용하도록 CI 단계 추가. 기존 회귀 테스트에 `SOUND:` 접두부, `w:` 가중치 및 `[선택지|선택지]` 보존 검증 케이스 추가.

## 검사 기준과 한계

기존 원문 기준으로 번역 파일의 키 중복, 문장 변형 순서·개수, 선택 가중치, 필수 `@...@` 키, 무작위 표현 수, `VISUAL:`/`SOUND:` 접두부를 대조. 별도 정적 사전 검사에서 **오류 0건**.

**주의:** 원문의 `monspeak.txt`에는 `_laughs_` 중복 키가 1건 있다. 이번 배치에서 원문을 변경하지 않았다. 여기서 나타낸 비율은 오직 파일별 키 대응률이지 전체 게임 번역률이 아니며, 한국어 문장 뒤의 조사 `이(가)`·`을(를)` 등의 실제 출력은 Windows Tiles 실행 후 별도 평가가 필요하다. 특히 다국어 동적 토큰, 이름 격조사, 음향 문구의 연결은 아직 런타임으로 검증하지 않았다.

## 이어서 할 작업

1. `monspeak.txt`의 남은 471개 키에서 참조 전용, 출력 없음, 실제 영어 대사를 나누고 인간형 공통 대사·고유 몬스터 긴 대사를 우선 처리.
2. `wpnnoise.txt`의 남은 47개 키 중 노래하는 검의 장문 노래·감정별 독백·특수 무기 대사를 단계별로 추가.
3. `godspeak.txt` 최상위 데이터의 기존 한국어 123줄을 보존하고 영어 문장만 재검토.
4. DCSS 0.34.1 Windows Tiles에서 데이터베이스 로딩, 변수 치환, 줄바꿈과 메시지 자연스러움을 통합 테스트.

검증 명령:

```powershell
python tools/dcss-extractor/scripts/audit_monspeak_ko.py --original source/dat/database/monspeak.txt --localized source/dat/database/ko/monspeak.txt
python tools/dcss-extractor/scripts/audit_monspeak_ko.py --original source/dat/database/wpnnoise.txt --localized source/dat/database/ko/wpnnoise.txt
```
