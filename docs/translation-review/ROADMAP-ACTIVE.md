## 목표와 완료 정의

DCSS 0.34.1 Windows Tiles에서 일반 게임 플레이 전반을 자연스러운 한국어로 출력하고, 회귀 테스트를 통과한 실행 패키지를 배포한다. '설명 키 100%'와 '게임 전체 100%'는 별개의 개념이다. **번역률은 검증된 실제 출력 호출부/대응 데이터 키/실행 테스트를 분리해서 기록하며 전체 백분율을 추정하지 않는다.**

## 작업 운영 규칙

1. 매 세션 시작: **이 파일 → PR #174 및 이후 PR → 최신 Actions → 변경 소스** 순서로 확인한다.
2. 코드 작성 전: 원문과 현재 한국어가 이미 존재하는지 확인한다. 영어 원문 폴백, 내부 식별자·치환 변수는 보존한다.
3. 변경 기록은 **파일/고유 번역 패턴/실제 출력 호출 위치/진단용 개수/빌드 HEAD와 결과**를 분리해 남긴다.
4. C++ 번역은 부분 빌드가 아닌 변경 파일 전체를 검증한다. CI가 실행 중이면 성공이라고 적지 않는다.
5. Draft PR의 대량 묶음을 우선 활용하고 소규모 PR을 남발하지 않는다. 위험한 구조 변경은 별도 작업 단위로 분리한다.
6. 새 작업이 끝나면 이 문서의 체크박스·검증 SHA·남은 작업을 갱신한다. 단순 계획 반복 대신 실제 파일 수정과 검증을 우선한다.
7. 검증되지 않은 번역은 '반영/검증 대기'라고 표기하고, Windows에서 직접 확인하지 않은 항목은 'Windows QA 미실시'로 표기한다.
