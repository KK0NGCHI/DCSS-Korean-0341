## 주의 및 후속 작업

1. `wpnnoise.txt`의 **100%는 이 파일의 원문 고유 키 대응률만 의미함**. 사용자 인터페이스, 다른 DB나 C++ 전체 번역 완료를 의미하지 않음.
2. 일부 원문 가사는 음악·오페라의 패러디와 인용으로, 현재는 원문 의미를 우선하여 번역했음. 원전·고유명사 및 표현의 통일성은 추후 인간 검토 필요.
3. `@_godless_sorter_@`, `@_musical_topic_@`처럼 다른 항목을 삽입하는 문장은 실제 재생 때 한국어 어순/조사 검증이 필요함.
4. 다음 우선순위: `monspeak.txt` 남은 302개 키 가운데 독립적인 영어 대사 본문 번역, mixed-language `godspeak.txt`, Windows Tiles 통합 게임 테스트.
