%%%%
flame cloud

맹렬하게 타오르는 불꽃 구름이다. 화염에 완전히 면역이 아닌 생명체는 안에 머무는 동안 피해를 입는다.

구름을 통과하는 원거리 냉기 공격의 사거리가 크게 줄어들며, 그 과정에서 구름이 사라진다.

물가나 물 위에서는 열기로 인해 주변에 증기가 발생한다.
%%%%
noxious fumes cloud

숨을 막히게 하는 악취 가스 구름이다. 안에 머무는 생명체는 독 저항이 없다면 혼란에 빠질 위험이 있다. 강하고 경험 많은 생명체일수록 영향을 덜 받는다.
%%%%
freezing vapour cloud

얼어붙을 듯 차가운 공기 구름이다. 냉기에 완전히 면역이 아닌 생명체는 안에 머무는 동안 피해를 입는다.

구름을 통과하는 원거리 화염 공격의 사거리가 크게 줄어들며, 그 과정에서 구름이 사라진다.
%%%%
poison gas cloud

치명적인 독가스 구름이다. 독 저항이 없는 생명체는 안에 머무는 동안 중독되고 직접적인 피해도 입는다.
%%%%
_smoke_cloud_

색색의 연기 구름이다. 천식이 있는 이들에게나 해로울 뿐 무해하다.

%%%%
translocational energy cloud

조금 전 이곳에 있다가 근처나 같은 층의 다른 곳, 심지어 현실 너머 심연으로 추방되어 사라진 생명체의 흔적이다. 어떤 마법사들은 공간을 불가능한 방식으로 왜곡하는 마법에 우주가 보이는 일종의 '알레르기 반응', 곧 우주적인 재채기라고 설명한다. 형이상학적으로는 불쾌할지 몰라도 다른 해는 없다.
%%%%
spreading flames cloud

맹렬한 산불이다. 화염에 완전히 면역이 아닌 생명체는 안에 머무는 동안 피해를 입는다. 불길은 간헐적으로 솟구쳐 주변에 작은 불을 퍼뜨린다. 근처의 나무는 불쏘시개가 되기 쉽다.

구름을 통과하는 원거리 냉기 공격의 사거리가 크게 줄어들며, 그 과정에서 구름이 사라진다.

물가나 물 위에서는 열기로 인해 주변에 증기가 발생한다.
%%%%
steam cloud

뜨거운 증기 구름이다. 안에 있는 생명체는 약간의 피해를 입으며, 화염 저항이 있으면 피해가 더 줄어든다.
%%%%
ink cloud

물을 가득 메운 먹물 구름이다.
%%%%
calcifying dust cloud

석화시키는 구름이다. 잠시라도 안에 머무는 생명체는 몸이 돌로 변하기 시작하지만, 경험이 많은 생명체는 그 효과를 견딜 수도 있다.
%%%%
blessed fire cloud

신성한 힘이 깃든 불꽃 구름이다. 선한 신을 섬기는 존재는 영향을 받지 않는다. 그 밖의 생명체는 피해를 입고, 언데드와 악마는 특히 큰 피해를 입는다.
%%%%
foul pestilence cloud

역병을 품은 악취 구름이다. 안에 있는 살아 있는 생명체는 중독되며, 이동 속도까지 느려질 수 있다.
%%%%
thin mist cloud

옅은 안개다. 분위기만 자아낼 뿐 해롭지 않다.
%%%%
seething chaos cloud

혼돈이 들끓는 구름이다. 안에 있는 생명체에게 투명화부터 광폭화, 완전 마비에 이르기까지 다양한 예측 불가능한 효과가 발생한다.
%%%%
rain cloud

매우 좁은 지역에 내리는 소나기다. 잠시 유지되는 얕은 물웅덩이를 만들 수 있다. 불로 이루어진 존재는 빗속에 오래 머무는 것을 꺼린다.
%%%%
mutagenic fog cloud

순수하고 무질서한 마력이 반짝이는 안개로 응축된 것이다. 사실상 유독한 마법 폐기물이다. 안에 들어간 생명체는 마법 오염이 점점 쌓이고, 충분히 쌓이면 오염이 해소될 때 해로운 돌연변이가 발생한다.
%%%%
magical condensation cloud

고도로 응축된 마력이 지나간 흔적이다. 그 자체로는 완전히 무해하다.
%%%%
whirling frost cloud

극지 소용돌이의 바람이다. 안에 있는 대상에게 심각한 피해를 주며 냉기 저항으로도 일부만 줄일 수 있다.
%%%%
sparse dust cloud

성긴 먼지 구름이다. 분위기만 자아낼 뿐 해롭지 않다.
%%%%
spectral mist cloud

망령의 안개다. 언데드를 제외한 모든 생명체에 약한 피해를 준다. 시간이 지나면 위험하지만 수명이 짧은 망령 언데드가 안개 속에서 뭉쳐 나타난다.
%%%%
acidic fog cloud

살을 녹이는 산성 안개다. 안에 있는 대상에게 피해를 주고 부식을 일으킨다. 부식 저항이 있으면 효과에 면역이 된다.
%%%%
thunder cloud

어두운 폭풍 구름이다. 안에 있는 대상에게 간헐적으로 번개가 떨어지며, 전기 저항이 없으면 심각한 피해를 입는다.
%%%%
excruciating misery cloud

절망과 강령의 기운이 남아 있는 구름이다. 안에 갇힌 생명체는 최대 체력의 작은 비율을 반복해서 잃으며, 음에너지에 대한 보호가 있으면 효과가 줄어든다.
%%%%
white fluffiness cloud

하얗고 푹신해 보이는 구름이다. 베개로 쓸 만큼 단단하지는 않지만 묘하게 평온하다.
%%%%
salt cloud

먼지와 소금이 빠르게 소용돌이치는 구름이다. 안에 들어간 생명체의 눈과 피부를 따갑게 하지만 결국 무해하다.
%%%%
golden dust cloud

금빛으로 반짝이는 먼지 구름이다. 안에 있는 평의회 신도는 전투에서 엄청난 힘을 얻는다.
%%%%
smouldering embers cloud

희미하게 타오르는 잿불 구름이다. 위에 서 있는 생명체라면 쉽게 꺼뜨릴 수 있지만, 방치하면 맹렬한 불꽃 구름으로 번진다.
%%%%
wisps of flame cloud

불꽃과 작은 불티가 흩날린 흔적이다. 분위기만 자아낼 뿐 해롭지 않다.
%%%%
alcoholic mist cloud

증발한 밀주가 짙게 낀 안개다. 그 안을 걷기만 해도 취할 만큼 농도가 짙다.
%%%%
blastmotes cloud

불안정한 폭발 입자 구름이다. 불꽃이나 생명체에 닿으면 폭발한다. 충격파가 주변의 생명체를 밀어낸다.
%%%%
sparks cloud

전기 불꽃이 흩날린 흔적이다. 분위기만 자아낼 뿐 해롭지 않다.
%%%%
faint pestilence cloud

어딘가에서 새어 나오는 아주 희미한 역병의 기운이다. 아직 해로울 만큼 짙지는 않지만 빠르게 농도가 높아지고 있다.
%%%%
magnetised fragments cloud

최근 발생한 방전 때문에 아직 미세하게 떨리고 있는 자화된 금속 조각 수없이 많은 개로 이루어진 구름이다. 사라질 때까지 마그나볼트 주문의 인력 발생 지점으로 작용한다.
%%%%
bats cloud

너무 빽빽해서 셀 수 없을 정도로 많은 작은 흡혈박쥐 떼다. 그 안에 있는 언데드 외의 생명체를 끈질기게 공격하며, 졸음을 일으키는 물기로 점차 잠들게 만든다. 잠든 뒤에도 무방비한 몸에서 피를 빨아먹는다.
%%%%
rust cloud

산화성 증기 구름이다. 그 안에 있는 대상의 공격을 지속적으로 약화시키고 부식시키지만, 직접적인 피해는 극히 적다.
