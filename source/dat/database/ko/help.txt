# Korean overlay for interlevel travel and annotation help.

interlevel-travel.branch.prompt

<h>층간 이동 (구역 선택):
이동할 구역의 단축 문자를 눌러 선택하세요.
구역을 선택하면 해당 구역에서 이동할 층을 입력하게 됩니다.
자세한 도움말은 층 선택 화면에서 확인할 수 있습니다.
<w>Tab</w> : 마지막 층간 이동을 반복합니다.
<w>.</w> : 현재 구역의 다른 층으로 이동합니다.
<w><<</w> : 가장 가까운 올라가는 계단을 이용합니다.
<w>></w> : 가장 가까운 내려가는 계단을 이용합니다.
<w>Ctrl-P</w> : 상위 구역의 층으로 이동합니다.
<w>*</w> : 설정한 경유지를 표시합니다.
<w>0</w>-<w>9</w> : 지정한 번호의 경유지로 이동합니다.
<w>_</w> : 발견한 제단 목록을 표시합니다.

interlevel-travel.depth.prompt

<h>층간 이동 (선택한 구역의 층 지정)
이동할 층 번호를 입력하고 Enter를 누르거나 아래 키를 사용하세요.
<w>Enter</w> : 기본으로 선택된 층으로 이동합니다.
<w>0</w> : 현재 구역의 입구로 이동합니다.
<w><<</w> : 기본 층을 현재 층보다 1층 위로 바꿉니다.
<w>></w> : 기본 층을 현재 층보다 1층 아래로 바꿉니다.
<w>-</w> 또는 <w>p</w> : 기본 선택을 상위 구역으로 바꿉니다.
<w>$</w> : 이 구역에서 방문한 가장 깊은 층을 선택합니다.
<w>^</w> : 기본 층을 현재 구역의 입구로 바꿉니다.

interlevel-travel.altar.prompt

<h>층간 이동 (제단으로 이동):
신의 이름 첫 글자에 해당하는 단축 문자를 누르세요(광휘의 존재는 숫자 1).
이를 사용해 여행할 제단을 선택합니다.
신을 선택하면 가장 가까운 해당 제단으로 이동하기 시작합니다.
<w>Enter</w> : 마지막 층간 이동을 반복합니다.

annotate.prompt

<h>주석 달기 (층 선택):
<w>Enter</w> 또는 <w>.</w> : 현재 층에 주석을 답니다.
<w>문자</w> : 해당 문자에 대응하는 구역의 층에 주석을 답니다.
<w><<</w> : 위층에 주석을 답니다.
<w>></w> : 아래층에 주석을 답니다.
<w>Ctrl-P</w> : 상위 구역의 층에 주석을 답니다.
<w>!</w> : 던전 구역 목록을 표시합니다.

pick-up

<h>아이템 줍기와 버리기</h>
<h>이동 및 아이템 선택</h>
방향키와 <w>pgdn</w>/<w>pgup</w>, <w>home</w>, <w>end</w>로 아이템을 선택합니다.
<w>Space</w> 또는 <w>.</w>으로 줍거나 버릴 아이템을 선택 또는 해제합니다.
아이템의 문자 키를 눌러도 선택 상태가 바뀝니다.
장비, 물약, 두루마리, 발동형 아이템은 각각 별도의 페이지에 표시됩니다.
<w>왼쪽 방향키</w>와 <w>오른쪽 방향키</w>로 페이지를 전환합니다.
<w>Return</w>으로 선택을 확정합니다.
문자 키보다 먼저 수량을 입력하면 그 수량만 선택합니다.
<h>정규 표현식</h>
<w>Ctrl-F</w>로 단어나 정규 표현식을 입력하면 일치하는 아이템이 모두 선택됩니다.
<h>분류별 단축키</h>
다음 키로 아이템 종류를 빠르게 선택할 수 있습니다.
<w>!</w> 물약  <w>(</w> 무기  <w>)</w> 탄약  <w>[</w> 방어구
<w>/</w> 마법봉  <w>|</w> 마법 지팡이  <w>?</w> 두루마리  <w>:</w> 책
<w>"</w> 목걸이  <w>=</w> 반지  <w>}</w> 기타 아이템
전체 선택: <w>,</w> 모두 선택  <w>*</w> 반전  <w>-</w> 모두 해제
<w>;</w> 마지막으로 장착 해제한 아이템 선택
버리기에서 <w>,</w>는 <w>drop_filter</w> 옵션에 따라 선택 범위를 제한합니다.
기본값은 쓸모없는 아이템 모두입니다.

known-menu

<h>알려진 아이템 목록</h>
<h>이동 및 아이템 선택</h>
방향키, <w>pgdn</w>/<w>pgup</w>, <w>home</w>, <w>end</w>로 종류를 선택합니다.
<w>Space</w> 또는 <w>.</w>으로 해당 종류의 자동 줍기 상태를 변경합니다.
아이템 종류의 문자 키를 눌러도 자동 줍기가 전환됩니다.
<h>아이템 종류 선택</h>
회색으로 표시된 종류는 설정 파일의 기본 자동 줍기 규칙을 따릅니다.
캐릭터에게 쓸모없는 아이템은 <darkgrey>어두운 회색</darkgrey>으로 표시됩니다.
종류를 선택하면 기본 규칙을 덮어쓰며 <w>흰색</w>으로 표시됩니다.
<w>+</w> 해당 종류를 자동으로 줍습니다.
<w>-</w> 해당 종류를 자동으로 줍지 않습니다.
해당 분류의 미감정 아이템 전체에 대해서도 자동 줍기를 전환할 수 있습니다.
<h>분류별 단축키</h>
다음 키로 분류에 속하는 모든 종류를 선택할 수 있습니다.
<w>!</w> 물약  <w>?</w> 두루마리  <w>(</w> 탄약  <w>"</w> 목걸이
<w>=</w> 반지  <w>/</w> 마법봉  <w>|</w> 마법 지팡이
전체 선택: <w>*</w> 선택 반전  <w>^</w> 모두 기본값으로 초기화
<h>감정 및 미감정 아이템 보기</h>
<w>\</w> 및 <w>-</w>로 감정한 아이템과 미감정 아이템 목록을 전환합니다.
미감정 아이템 목록에서는 위의 설정 변경 기능을 사용할 수 없습니다.
<h>자동 줍기 기본값 복원</h>
<w>Ctrl-D</w> 다음에 아이템 문자나 분류 단축키를 누르면
해당 설정의 예외를 해제하고 기본값을 복원합니다.
<h>정규 표현식</h>
<w>Ctrl-F</w>로 단어나 정규 표현식을 입력할 수 있습니다.
조건과 일치하는 아이템이 모두 선택됩니다.
