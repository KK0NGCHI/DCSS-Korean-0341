interlevel-travel.branch.prompt

<h>층간 이동 (구역 선택):
이동할 구역의 단축 문자를 눌러 선택하세요.
구역을 선택하면 해당 구역에서 이동할 층을 입력하게 됩니다.
자세한 도움말은 층 선택 화면에서 확인할 수 있습니다.
<w>Tab</w> : 마지막 층간 이동을 반복합니다.
<w>.</w> : 현재 구역의 다른 층으로 이동합니다.
<w><<</w> : 가장 가까운 올라가는 계단을 이용합니다.
<w>></w> : 가장 가까운 내려가는 계단을 이용합니다.
<w>Ctrl-P</w> : 상위 구역의 층으로 이동합니다.
<w>*</w> : 설정한 경유지를 표시합니다.
<w>0</w>-<w>9</w> : 지정한 번호의 경유지로 이동합니다.
<w>_</w> : 발견한 제단 목록을 표시합니다.

이동할 층 번호를 입력하고 Enter를 누르거나 아래 키를 사용하세요.
<w>Enter</w> : 기본으로 선택된 층으로 이동합니다.
<w>0</w> : 현재 구역의 입구로 이동합니다.
<w><<</w> : 기본 층을 현재 층보다 1층 위로 바꿉니다.
<w>></w> : 기본 층을 현재 층보다 1층 아래로 바꿉니다.
<w>-</w> 또는 <w>p</w> : 기본 선택을 상위 구역으로 바꿉니다.
<w>$</w> : 이 구역에서 방문한 가장 깊은 층을 선택합니다.
<w>^</w> : 기본 층을 현재 구역의 입구로 바꿉니다.

<h>이동 및 아이템 선택</h>
방향키와 <w>pgdn</w>/<w>pgup</w>, <w>home</w>, <w>end</w>로 아이템을 선택합니다.
<w>Space</w> 또는 <w>.</w>으로 줍거나 버릴 아이템을 선택 또는 해제합니다.
아이템의 문자 키를 눌러도 선택 상태가 바뀝니다.
장비, 물약, 두루마리, 발동형 아이템은 각각 별도의 페이지에 표시됩니다.
<w>왼쪽 방향키</w>와 <w>오른쪽 방향키</w>로 페이지를 전환합니다.
<w>Return</w>으로 선택을 확정합니다.
문자 키보다 먼저 수량을 입력하면 그 수량만 선택합니다.
<h>정규 표현식</h>
<w>Ctrl-F</w>로 단어나 정규 표현식을 입력하면 일치하는 아이템이 모두 선택됩니다.
<h>분류별 단축키</h>
다음 키로 아이템 종류를 빠르게 선택할 수 있습니다.
<w>!</w> 물약  <w>(</w> 무기  <w>)</w> 탄약  <w>[</w> 방어구
<w>/</w> 마법봉  <w>|</w> 마법 지팡이  <w>?</w> 두루마리  <w>:</w> 책
<w>"</w> 목걸이  <w>=</w> 반지  <w>}</w> 기타 아이템
전체 선택: <w>,</w> 모두 선택  <w>*</w> 반전  <w>-</w> 모두 해제
<w>;</w> 마지막으로 장착 해제한 아이템 선택
버리기에서 <w>,</w>는 <w>drop_filter</w> 옵션에 따라 선택 범위를 제한합니다.
기본값은 쓸모없는 아이템 모두입니다.

known-menu

<h>알려진 아이템 목록</h>
<h>이동 및 아이템 선택</h>
방향키, <w>pgdn</w>/<w>pgup</w>, <w>home</w>, <w>end</w>로 종류를 선택합니다.
<w>Space</w> 또는 <w>.</w>으로 해당 종류의 자동 줍기 상태를 변경합니다.
아이템 종류의 문자 키를 눌러도 자동 줍기가 전환됩니다.
<h>아이템 종류 선택</h>
회색으로 표시된 종류는 설정 파일의 기본 자동 줍기 규칙을 따릅니다.
캐릭터에게 쓸모없는 아이템은 <darkgrey>어두운 회색</darkgrey>으로 표시됩니다.
종류를 선택하면 기본 규칙을 덮어쓰며 <w>흰색</w>으로 표시됩니다.
<w>+</w> 해당 종류를 자동으로 줍습니다.
<w>-</w> 해당 종류를 자동으로 줍지 않습니다.
해당 분류의 미감정 아이템 전체에 대해서도 자동 줍기를 전환할 수 있습니다.
<h>분류별 단축키</h>
다음 키로 분류에 속하는 모든 종류를 선택할 수 있습니다.
<w>!</w> 물약  <w>?</w> 두루마리  <w>(</w> 탄약  <w>"</w> 목걸이
<w>=</w> 반지  <w>/</w> 마법봉  <w>|</w> 마법 지팡이
전체 선택: <w>*</w> 선택 반전  <w>^</w> 모두 기본값으로 초기화
<h>감정 및 미감정 아이템 보기</h>
<w>\</w> 및 <w>-</w>로 감정한 아이템과 미감정 아이템 목록을 전환합니다.
미감정 아이템 목록에서는 위의 설정 변경 기능을 사용할 수 없습니다.
<h>자동 줍기 기본값 복원</h>
<w>Ctrl-D</w> 다음에 아이템 문자나 분류 단축키를 누르면
해당 설정의 예외를 해제하고 기본값을 복원합니다.
<h>정규 표현식</h>
<w>Ctrl-F</w>로 단어나 정규 표현식을 입력할 수 있습니다.
조건과 일치하는 아이템이 모두 선택됩니다.

spell-library

<h>주문 목록</h>
<w>Tab</w> 또는 <w>!</w> : <w>암기</w>, <w>설명</w>, <w>숨기기</w>, <w>표시</w> 화면을 순서대로 전환합니다.
<w>Shift-Tab</w> : 이전 화면으로 전환합니다.
<w>Ctrl-F</w> : 정규 표현식으로 주문 목록을 필터링합니다.
<w>?</w> : 이 도움말을 표시합니다.
기본적으로 주문 목록은 <w>암기</w> 화면에서 열립니다. 주문을 암기하려면
해당 주문의 문자 키를 누르세요. 주문 설명을 읽으려면 <w>Tab</w>으로
<w>설명</w> 화면으로 이동한 다음 해당 주문의 문자 키를 누르세요.
모든 주문을 암기할 필요는 없으므로 <w>표시</w>와 <w>숨기기</w> 화면을
활용하면 편리합니다. <w>숨기기</w> 화면에서 주문의 문자 키를 누르면
<w>암기</w>와 <w>설명</w> 화면에서 숨겨집니다. 숨긴 주문은 <w>표시</w> 화면에서
같은 방법으로 다시 표시할 수 있습니다.
<w>auto_hide_spells</w> 옵션을 켜면 새로 발견한 주문을 기본적으로 숨깁니다.
<w>Ctrl-F</w>로 주문 목록을 필터링할 수 있으며, 설정한 필터는 목록을 닫았다가
다시 열거나 <w>Ctrl-F</w>로 변경할 때까지 유지됩니다.
입력란에서 아무것도 입력하지 않고 <w>Enter</w>를 누르면 필터가 해제됩니다.
주문 이름과 주문 계열을 기준으로 검색할 수 있습니다.

skill-menu

<h>기술 훈련 관리</h>
몬스터를 처치하거나 일부 다른 활동을 하면 경험치를 얻습니다.
이 경험치는 기술 훈련에 사용됩니다. 기술 화면에서 훈련할 기술을 선택합니다.
기술의 문자 키를 누르면 훈련 상태를 순서대로 변경할 수 있습니다.
<darkgrey>- 비선택</darkgrey> : 해당 기술을 훈련하지 않습니다.
+ 선택 : 해당 기술을 훈련합니다.
<w>* 집중</w> : 해당 기술에 더 높은 훈련 비중을 부여합니다.
대문자 키를 누르면 해당 기술만 선택하고 다른 기술은 모두 해제합니다.
하나의 기술에 집중해서 훈련할 때 편리합니다.
<w>/</w> 키로 자동 훈련과 수동 훈련을 전환합니다.
- 자동 : 기술을 사용한 정도에 따라 훈련 비중이 정해집니다.
- 수동 : 활성화한 기술에 경험치를 고르게 분배합니다.
훈련 목표 모드에서는 원하는 기술 레벨을 지정할 수 있습니다.
목표에 도달하면 해당 기술의 훈련이 자동으로 중지됩니다.
훈련 속도에는 다음 요소들이 영향을 줍니다.
- 적성 : 적성 열에 <white>흰색</white>으로 표시됩니다. 수치가 높으면
같은 기술을 올리는 데 필요한 경험치가 적으며 종족에 따라 달라집니다.
- 기술 교본 : 특정 기술의 적성에 <lightred>+4</lightred> 보너스를 주는 희귀한 책입니다.
관련 기술의 교차 훈련이나 일부 신의 능력도 기술 수준을 변경할 수 있습니다.
감소한 기술은 <magenta>자홍색</magenta>, 증가한 기술은 <green>녹색</green>으로 표시됩니다.
훈련 비율은 <brown>갈색</brown>으로 표시하며 경험치가 해당 기술에 배분되는 비중입니다.
기술 선택 이외에도 다음 단축키를 사용할 수 있습니다.
<w>/</w> : 자동/수동 훈련 모드 전환
<w>*</w> : 현재 쓸모없는 기술을 포함해 모두 표시
<w>?</w> : 기술 설명 보기
<w>_</w> : 기술 레벨 보정(신의 능력, 교차 훈련) 표시 전환
<w>!</w> : 훈련 비율, 기술 비용, 훈련 목표 표시 전환

<w>-</w> 또는 <w>+</w> : 지도 위아래로 20칸 스크롤.
<w>.</w> : 이동 시작(<w>Enter</w>, <w>,</w>, <w>;</w>도 가능).

<w>[</w> 또는 <w>]</w> : 한 층 위나 아래를 살펴봅니다.

<w>G</w> : 구역과 깊이를 선택해 다른 층을 살펴봅니다.
<w>o</w> : 다음 자동 탐험 목적지로 커서를 옮깁니다.
<w>{</w> 또는 <w>}</w> : 지도 축소 또는 확대(타일 모드 전용).

<w>\</w> 또는 <w>Tab</w> : 상점과 차원문 순회.

<w>O</w> : 모든 아이템을 역방향으로 순회.
